# Homebrew tap for Koshka

This repository hosts a Homebrew tap for the prebuilt `kosh` binary from the
[fennec-support/kosh](https://github.com/fennec-support/kosh) latest release.

Tap to it:
```sh
brew tap fennec-support/kosh
```

Install directly:
```sh
brew install fennec-support/kosh/kosh
```

Homebrew needs network access to load the formula.
